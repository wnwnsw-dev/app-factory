# Series Library — context

Log everything I've watched or read in one place.

## What I log
- Cover, title
- Type: manga, manhwa, book, movie, series, other
- Rating
- Summary (optional)
- Chapters / episodes
- Status: plan to read, reading, complete, dropped

## Scope
- One private library, local only, no accounts
- v0: first page shows a grid of covers + titles using dummy data; adding/editing comes later

## Success
I can see my whole library at a glance on the first screen.
